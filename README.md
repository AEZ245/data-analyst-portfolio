# 📊 Pokémon Operations & Combat Analytics Dashboard

## 🎯 Project Overview
An advanced exploratory data analysis and interactive operational dashboard built to evaluate Pokémon combat statistics, population distributions across typings, and performance thresholds. Designed from the ground up for dynamic user-driven filtering and speed-to-insight.

## 🛠️ Tech Stack & Tools
* **Business Intelligence:** Power BI (Interactive Range Sliders, Hierarchical Slicers, KPI Cards, Clustered Column & Bar Charts)
* **Data Cleansing & Prep:** Excel (`XLOOKUP`, conditional aggregations, data hygiene)
* **Version Control:** GitHub

## 📈 Key Insights & Findings
* **Population Volume:** **Water**-type Pokémon make up the largest overall share of the dataset, closely followed by Normal and Grass.
* **Combat Efficiency:** Despite having lower overall population counts, **Dragon**-type Pokémon consistently dominate the highest average base stat totals across the board.

## 🎛️ Dashboard Layout & UX Architecture
* **Categorical Control Panel (Left):** Multi-select filtering handling Primary and Secondary types (`Type I`, `Type II`) seamlessly.
* **Core Analytics Zone (Center):** 
  * High-level KPI card tracking total dynamic record counts.
  * Side-by-side comparative analysis of population volume per type vs. average combat power per type.
* **Parametric Filtering Engine (Right):** Granular numeric range sliders built across all core combat attributes (`Total`, `HP`, `Atk`, `Def`, `SpA`, `SpD`, `Spe`), allowing stakeholders to isolate specific performance tiers on the fly (e.g., filtering for high-speed, elite-stat Pokémon).
